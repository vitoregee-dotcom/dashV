# Prompts pro Gemini — banco de ícones do PartsFlow

Duas famílias, com os MESMOS 208 ícones em cada uma (mesma lista, mesma ordem):
- **Minimalista** = traço fino, igual aos ícones "Traço (WhatsApp)" da extensão.
- **Intuitiva** = 3D colorido, profissional.

Como pedir: 1 pedido = 1 folha com 16 ícones (grade 4×4). São 13 folhas por família.
Copie o PROMPT BASE da família + o LOTE (a lista de 16), nessa ordem. A ordem importa:
é por ela que o sistema dá o nome de cada ícone sozinho quando você me mandar as folhas.

---

## 1) PROMPT BASE — MINIMALISTA (traço)

```
Create a single image: a 4x4 grid sheet of 16 UI icons, evenly spaced, each centered in its own square cell, same visual size.
Style: minimalist outline icons for a professional business web app, in the style of Lucide / Feather icons.
- Single color: pure black (#000000) strokes only, no fill, no color, no gradients, no shadows, no 3D.
- Consistent 2px stroke on a 24x24 grid, rounded line caps and rounded joins, simple geometric shapes, generous padding.
- Pure flat white background (#FFFFFF), no cell borders, no grid lines, no labels, no text, no numbers, no letters inside the icons.
- No brand logos.
- All 16 icons must look like they belong to the same icon set (same stroke, same corner radius, same level of detail).
- Order: left to right, top to bottom, exactly as listed:
```

## 2) PROMPT BASE — INTUITIVA (3D)

```
Create a single image: a 4x4 grid sheet of 16 app icons, evenly spaced, each centered in its own square cell, same visual size.
Style: modern, clean, professional 3D icons, similar to Microsoft Fluent 3D icons — soft matte "clay" material with a subtle gloss,
smooth rounded forms, soft studio lighting from the top left, gentle soft shadow directly under each object, slight 3/4 front view, same camera angle for all.
- Limited corporate color palette: deep navy blue #1F4E79, orange accent #E67E22, white, light gray #D9DEE5, and dark gray #3A4654. Use orange only as a small accent.
- One simple object per icon, no clutter, no tiny details, readable at 32px.
- Solid flat magenta background (#FF00FF) filling the whole image, no cell borders, no grid lines, no labels, no text, no numbers, no letters, no brand logos.
- All 16 icons must look like one consistent icon set (same material, same lighting, same size, same angle).
- Order: left to right, top to bottom, exactly as listed:
```

## Dicas
- Se o Gemini errar a ordem ou repetir um ícone, peça de novo só aquele lote ("same sheet, but icon 7 must be ...").
- Se uma folha sair com estilo diferente das outras, mande a 1ª folha boa junto e escreva: "Match exactly the style of the attached sheet."
- Pode me mandar as folhas como vierem (print ou arquivo). Eu recorto, tiro o fundo, dou o nome e guardo no sistema.
- Quer mais ícones depois? É só criar o Lote 14 em diante com o mesmo prompt base.
